Основными проблемами при расширении нагрузки являяются:
1. Синхронные взаимодействия между сервисам
2. Задержка в получении данных отстраховых
3. Рост количества ошибок кратно количеству новых контрагентов.

Решением явлется переход  на паттерн Event Sourcing при взаимодейтсвии между сервисами:
core-app, ins-comp-settlement и ins-product-aggregator.
Для обеспечения согласованности данных будет использован паттерн Transactional outbox
